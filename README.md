# Connect — Facebook-style News Feed Project

A professional academic social networking project built with **PHP, HTML5, CSS3, MySQL and XAMPP**.

## Features
- Register with email and/or phone number
- Login with email or phone number
- Secure password hashing
- Profile picture upload
- Text and image posts
- Newest-first news feed
- Likes and comments
- Friend requests with accept/reject
- Responsive Facebook-inspired layout
- Light/dark mode
- Animated cards, hover states and subtle electric/glow borders
- No React, Laravel, Node.js, Spring Boot, REST API or framework

## Run with XAMPP
1. Copy `facebook-news-feed` into XAMPP's `htdocs` directory.
2. Start **Apache** and **MySQL**.
3. Open phpMyAdmin.
4. Import `database/facebook.sql`.
5. Check `config/database.php` if your MySQL credentials differ.
6. Visit `http://localhost/facebook-news-feed/`.

## Upload directories
The application stores profile images in `uploads/profiles/` and post images in `uploads/posts/`.
